hop 02 about

Infrastructure that stops being interesting

I run cloud and edge infrastructure for a portfolio of high-traffic publishing and fintech-adjacent web properties — the kind where a bad WAF rule costs traffic by lunchtime and a mis-sized task definition costs money all month.

Most of my work sits in three places: the edge, where Cloudflare rules decide who gets served and how fast; the pipeline, where changes ship through Terraform and GitHub Actions instead of a console; and the bill, where right-sizing and observability turn guesswork into a number someone can act on.

I like the unglamorous parts: least-privilege IAM, backup jobs that actually restore, migrations planned far enough ahead that nobody notices them happening.
